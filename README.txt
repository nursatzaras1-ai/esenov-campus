YESSENOV CAMPUS

Файлдар:
index.html — басты файл.
style.css — дизайн.
app.js — курстар, тесттер, пікірлер.

Компьютерде ашу:
ZIP архивін шығарып, index.html файлын браузерде аш.
Файлдардың барлығы бір папкада қалуы керек.

Vercel:
1. GitHub-та жаңа repository жаса.
2. Осы папканың ішіндегі файлдарды repository түбіріне жүкте.
3. Vercel-де Add New > Project > Import таңда.
4. Framework Preset: Other.
5. Build Command: бос қалдыр.
6. Output Directory: файлдар орналасқан түбір (.)
7. Deploy бас.

Бұл — демо жоба. Нақты авторизация және серверлік дерекқор жоқ.
Бағалар — үлгі. Курс тестінің нәтижесі жауапқа қарай есептеледі.
Оқу барысы мен пікірлер осы браузердің localStorage жадында сақталады.
Пікірлер оқытушыларға жіберілмейді.
Python бұл нұсқаға қосылмаған.
