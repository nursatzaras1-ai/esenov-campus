PYTHON АНАЛИТИКА — ЖАҢАРТУ

Не қосылды:
- api/analytics.py: Vercel-де Python арқылы есептеу.
- analytics.js: аналитика беті және Python API-ға сұрау.
- requirements.txt: сыртқы Python кітапханалары қажет емес.
- .python-version: Python 3.12 (қосымша нұсқа бекітуі).
- index.html және app.js жаңартылған.
- Аккаунт / Passkey файлдары сақталған.

БІРГЕ ЖАРИЯЛАУ
1. ZIP архивін шығарып ал.
2. GitHub > esenov-campus > Add file > Upload files.
3. Yessenov-Campus-Python папкасының ІШІНДЕГІ барлық файлды,
   api және vendor папкаларын жүкте. ZIP-тің өзін жүктеме.
4. Commit changes бас.
5. Vercel > Deployments бөлімінде жаңа жариялау Ready болғанын күт.
   Framework: Other. Root Directory: repository түбірі.
   Build Command: бос. Output Directory: түбір (.).
   api папкасын тек статикалық файл ретінде шығаратын өз build қадамын қоспа.
6. https://esenov-campus.vercel.app бетін Ctrl+F5 арқылы жаңарт.
7. Сол жақтан «Python аналитика» аш.
8. Сервер: Python белгісі мен есеп көрсетілуі керек.

ТЕКСЕРУ
Курстардан бір сабақты аяқтап, тест тапсыр. Бір пікірге жұлдыз қой.
«Python аналитика» > «Қайта есептеу» бас.
CSV есебін жүктеп, Excel-де аш.
Қосымша тексеру: https://esenov-campus.vercel.app/api/analytics
Бұл мекенжай {status: ok, engine: Python} жауабын беруі керек.

ҚАЛАЙ ЖҰМЫС ІСТЕЙДІ
JavaScript браузердегі сабақ нөмірлерін, соңғы тест ұпайларын және рейтинг
жұлдыздарын /api/analytics мекенжайына POST арқылы жібереді.
Python деректерді тексеріп, көрсеткіштерді есептейді және JSON/CSV қайтарады.
Есімдер, email, парольдер мен пікір мәтіндері жіберілмейді.
Сервер есептің бастапқы деректерін сақтамайды.
Бұл API — жіберілген демо сандардың калькуляторы, ресми бағалар көзі емес.
Бүкіл университеттің немесе бірнеше студенттің ортақ аналитикасы емес.
Қазір браузерлік демо деректер аккаунттар арасында бөлінбейді.
Нақты студент деректерін қосу үшін серверлік сақтау мен рұқсаттар қажет.

Есеп формулалары:
- Аяқталған сабақтар / 18 * 100.
- Курс аяқталды: 3 сабақтың бәрі аяқталған.
- Тест орташа ұпайы: тапсырылған курстардың соңғы ұпайларының орташа мәні.
  Тапсырылмаған тест орташаға кірмейді; 0 ұпай кіргізіледі.
- Рейтинг: барлық пікір жұлдыздарының орташа мәні.
- Үлгі пән бағалары есепке кірмейді.

Тексерілді: Python HTTP API, бос деректер, 0 ұпай, рейтинг орташа мәні,
қайталанған сабақтар, қате сұраулар, CSV файлы. JS синтаксисі тексерілді.
Vercel-дегі жариялау мен тірі интерфейс пайдаланушы жүктеген соң тексеріледі.
